# Roadmap Scene Composer

## Fase MVP 2.5D

El MVP 2.5D permite validar el valor comercial del composer sin entrar todavia en una escena 3D calibrada.

Incluye:

- Subir imagen de una estancia vacia.
- Colocar previews PNG/WebP/SVG de productos reales del catalogo.
- Mover productos sobre la imagen.
- Escalar productos.
- Rotar productos.
- Eliminar elementos.
- Ordenar capas basicas.
- Exportar composicion como PNG cuando el navegador lo permite.
- Exportar proyecto como JSON.
- Descargar listado de productos usados.
- Guardado local en `localStorage`.

## Fase futura 3D

La fase 3D requiere resolver problemas tecnicos de mayor precision:

- Calibracion de camara.
- Plano de suelo.
- Escala real.
- Sombras coherentes.
- Oclusion.
- Depth map.
- GLB reales dentro de escena.
- Hotspots de producto.
- Export para cliente.
- QA de perspectiva y medidas.

## Principio de producto

El composer 2.5D es una herramienta de propuesta visual conceptual. No sustituye una escena 3D calibrada, pero permite vender mas rapido una idea de staging, mobiliario y direccion visual.
