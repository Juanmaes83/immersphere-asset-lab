# Comedor Mediterraneo Premium

## Vision de coleccion

`dining-room-mediterranean-premium` es la coleccion activa de comedor para Decor Asset Lab. Cubre una escena de comedor mediterraneo premium con productos reales de IKEA: mesas, sillas, bancos, aparador, vitrina y alfombra.

## Cobertura

- Estado: active
- Room type: dining-room
- Objetivo: 16 assets reales
- Cobertura actual: 16/16
- Uso: staging visual, catalogo interactivo, Room Designer Lite, Scene Composer y propuestas comerciales para vivienda amueblada

## Uso comercial

- Home staging de comedor y zona social de vivienda.
- Propuestas de vivienda premium para inmobiliarias y promotoras.
- Demo de interiorismo con catalogo real y piezas de madera natural.
- Room Designer Lite para composiciones rapidas con plantilla de comedor.

## Notas de QA

- Los 16 GLB proceden de descarga manual autorizada.
- Las dimensiones quedan en `null` hasta revision de escala.
- Previews generadas con `npm run generate-previews`.
- Las categorias `bench`, `sideboard` y `display-cabinet` se aceptan en importer, schema y validador.
- La coleccion debe aparecer en viewer, composer, empty-room-staging y room-designer.
