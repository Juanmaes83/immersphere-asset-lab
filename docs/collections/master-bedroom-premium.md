# Dormitorio Principal Premium

## Vision de coleccion

`master-bedroom-premium` es la coleccion activa de dormitorio principal para Decor Asset Lab. Cubre una escena de dormitorio premium con productos reales de IKEA: cama, mesitas, almacenaje, tocador, espejo y alfombra.

## Cobertura

- Estado: active
- Room type: bedroom
- Objetivo: 16 assets reales
- Cobertura actual: 16/16
- Uso: staging visual, catalogo interactivo, developer showroom e interior design demo

## Uso comercial

- Home staging de dormitorio principal.
- Propuestas de vivienda premium para inmobiliarias y promotoras.
- Demo de interiorismo con catalogo real.
- Room Designer Lite para composiciones rapidas con paredes, suelo, vista y productos reales.

## Notas de QA

- Las dimensiones quedan en `null` hasta revision de escala.
- Previews generadas con `npm run generate-previews`.
- Las categorias nuevas se aceptan en importer, schema y validador.
- La coleccion debe aparecer en viewer, composer, empty-room-staging y room-designer.
