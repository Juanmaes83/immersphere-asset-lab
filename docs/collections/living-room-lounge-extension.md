# Salon Lounge Premium

## Vision de coleccion

`living-room-lounge-extension` es la extension activa de salon para Decor Asset Lab. Amplia el catalogo con sofas, sillones, butacas lounge, puf, reposapies, mesa de centro, mueble TV y cabinet de salon.

## Cobertura

- Estado: active
- Room type: living-room
- Objetivo: 20 assets reales
- Cobertura actual: 20/20
- Uso: staging visual de salon premium, catalogo interactivo, Room Designer Lite, Scene Composer y propuestas comerciales de interiorismo
