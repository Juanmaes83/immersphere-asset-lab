## Secuencia estratégica

```
Fase 0 ── Servicio interno premium
    │
    ├── Laboratorio de assets 3D autorizados
    ├── Catálogo local con control de licencias
    ├── Visor premium para demos internas
    └── QA visual y documentación de permisos
    │
    ↓ (Gate: acuerdo formal con 2+ marcas)
Fase 1 ── Demo comercial
    │
    ├── "Piso vacío → Piso amueblado" con catálogo real
    ├── Dossier PDF con listado de productos
    ├── Campaña inmobiliaria con staging virtual
    └── Propuesta comercial para agencias
    │
    ↓ (Gate: 3+ clientes piloto interesados)
Fase 2 ── Integración Immersphere Pro SaaS
    │
    ├── Asset Library en dashboard de tenant
    ├── Drag-and-drop de mobiliario a hotspots
    ├── Hotspot tipo PRODUCT con CTA
    └── Facturación como feature de plan Agency+
    │
    ↓ (Gate: 50+ tenants usando Asset Lab)
Fase 3 ── Integración Inmobiliarias + CRM
    │
    ├── Sección staging en web comercial
    ├── Presupuesto con líneas de mobiliario (CRM)
    └── Pipeline: lead → reforma + mobiliario
    │
    ↓ (Gate: demanda de marketplace externo)
Fase 4 ── Marketplace (futuro lejano)
    │
    ├── Biblioteca pública de packs por estilo/marca
    ├── Stripe para packs de pago
    ├── Revenue share con marcas
    └── "Shutterstock del mobiliario 3D" para PropTech
```

---

## Principios estratégicos

1. **Legal antes que código.** Ningún asset real entra sin permiso documentado.
2. **Pipeline antes que producto.** Primero construimos el sistema, luego lo vendemos.
3. **Demo antes que integración.** Primero enseñamos el valor, luego conectamos al SaaS.
4. **Interno antes que externo.** Primero lo usamos nosotros, luego lo ofrecemos a clientes.
5. **Marca por marca.** No negociamos con 20 marcas a la vez. Una a una, con contrato.
