# Demo comercial: Estancia vacia -> Estancia amueblada

## Objetivo comercial

Mostrar de forma inmediata como una imagen de estancia vacia puede convertirse en una propuesta visual amueblada con productos reales del catalogo Decor Asset Lab.

La demo reduce friccion comercial porque no exige explicar primero el viewer tecnico ni una escena 3D completa. El cliente ve el flujo: espacio vacio, producto real, composicion visual, listado y exportacion.

## Flujo de uso

1. Abrir la demo.
2. Usar la estancia de ejemplo o subir una imagen propia.
3. Elegir productos reales del catalogo.
4. Colocarlos sobre la escena.
5. Ajustar posicion, escala y rotacion.
6. Revisar listado de productos usados.
7. Exportar imagen o JSON.
8. Pasar a CTA comercial: staging, catalogo interactivo o composer avanzado.

## Segmentos objetivo

### Inmobiliarias

Ayuda a convertir viviendas vacias en espacios mas faciles de imaginar antes de visita o campana.

### Promotoras

Permite presentar viviendas tipo amuebladas antes de construir, entregar o producir renders finales.

### Interioristas

Sirve para crear propuestas rapidas con producto real y validar una direccion visual.

### Marcas

Demuestra como un catalogo puede aparecer dentro de experiencias inmobiliarias y material comercial.

## Entregables generables

- Imagen exportada.
- Listado de productos.
- Propuesta visual conceptual.
- Dossier comercial.
- Derivacion a demo 3D de catalogo.

## Limitaciones actuales

- Es 2.5D.
- No tiene escala fisica.
- No genera sombras reales.
- No calcula oclusion.
- No sustituye un render 3D calibrado.
- No carga GLB dentro de la composicion.
