# Demo comercial: Estancia vacia -> Estancia amueblada

## URL local

`http://localhost:3456/demos/empty-room-staging/`

## Objetivo

Transformar el Scene Composer MVP en una demo comercial mas guiada: estancia vacia, productos reales, propuesta visual, listado y exportacion.

## Incluye

- Landing comercial.
- Composer guiado 2.5D.
- Estancia de ejemplo SVG.
- Upload de imagen propia.
- Presets conceptuales.
- Export PNG.
- Export JSON de proyecto.
- Export JSON de listado.

## No incluye todavia

- Calibracion real de perspectiva.
- GLB dentro de la escena.
- Sombras reales.
- Oclusion.
- Backend.
